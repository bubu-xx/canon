# reconcile：突き合わせ

## 手順
1. 追加・更新された情報源（`.canon/sources/` の新しいファイル）を特定する
2. Canon の各要素について、その項目に関係する記述を新旧すべての情報源から探す
3. 判定：
   - 表現が違うだけで同じ意味 → そのまま（出典は最も具体的なものに）
   - 新しい版で値が変わった → 新しい版を出典に更新。旧版との違いは要素の値の履歴として Git に残る
   - 情報源どうしが食い違う → `conflict` にして全主張を claims に残し、質問を起票（ask スキル）
   - これまで unknown だった項目の根拠が見つかった → `confirmed` にして出典を付け、質問を `withdrawn` にする（context に理由を追記）
   - 粒度の違い（基本設計では1機能、詳細設計では3つ）→ 矛盾ではない。親子として derived_from でつなぐ
4. `canon validate` → `canon gaps` を実行し、変わった点（新しい矛盾・解消した空白）を利用者に報告する

推測で値を選ばないこと。どちらが正しいか決められないものは必ず conflict のまま残す。
