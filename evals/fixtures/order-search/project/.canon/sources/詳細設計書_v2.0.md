<!-- src: 詳細設計書 v2.0 シート7 B3:F5 -->
概要：条件に合う会員本人の注文を新しい順に返す

<!-- src: 詳細設計書 v2.0 シート7 B6 -->
起動：注文履歴画面の検索ボタン押下

<!-- src: 詳細設計書 v2.0 シート7 B8 -->
前提条件：ログイン済みであること

<!-- src: 詳細設計書 v2.0 シート7 B10:F14 -->
| 入力項目 | 必須 | 型 | 制約 |
|---|---|---|---|
| 注文日From | 任意 | 日付 | |
| 注文日To | 任意 | 日付 | |
| 商品名 | 任意 | 文字列 | 部分一致、100文字以内 |

<!-- src: 詳細設計書 v2.0 シート7 B16:F18 -->
処理：
1. 検索条件に会員IDと12か月以内の条件を加える
2. 注文日の降順で取得する

<!-- src: 詳細設計書 v2.0 シート7 B20:F24 -->
出力：注文番号、注文日、商品名、合計金額の一覧

<!-- src: 詳細設計書 v2.0 シート7 B30 -->
エラー：該当なしの場合は空の一覧を返す
